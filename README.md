# Odin Recipes

This project is part of [The Odin Project](https://www.theodinproject.com/) Foundations course. It is a basic recipe website built with HTML.

The website will contain a main index page with links to several recipe pages. Each recipe page will include information such as ingredients, preparation steps, and images.

By completing this project, I will demonstrate my understanding of basic HTML concepts, including:

- Creating and structuring HTML documents
- Using headings, paragraphs, lists, links, and images
- Creating links between multiple pages
- Organizing files and directories in a web project
- Using Git and GitHub to track and publish my work

This project is an opportunity to practice the fundamental skills needed to build websites from scratch and to become more comfortable working with HTML and version control.
